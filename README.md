# dmenu-unicode-mathematical-operators

A simple `dmenu` picker for Unicode Mathematical Operators (`U+2200`–`U+22FF`).

Select a symbol and it is copied directly to the clipboard.

## Dependencies

- `dmenu`
- One of:
  - `wl-copy`
  - `xclip`
  - `xsel`

## Usage

```sh
./dmenu_unicode_math.sh
````
